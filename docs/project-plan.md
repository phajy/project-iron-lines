# Project overview

- Download XMM-Newton spectra to look at, say, the 3-7 keV "clean" iron K line band
- Fit with narrow line + relativistically blurred reflection spectra
- Pick the best XMM-Newton observations, probably with EPIC-pn, and combine as needed
- See how well we can constrain spin, disc, corona geometries

# Resources

## Papers

NASA's [ADS](https://ui.adsabs.harvard.edu/) is the best way to find papers. You can also use ADS to find out which  papers cite a specific paper whcih can be helpful to find more recent papers on a specific topic.

- [An XMM-Newton survey of broad iron lines in Seyfert galaxies](https://ui.adsabs.harvard.edu/abs/2007MNRAS.382..194N/abstract) is an overview of broad iron lines from 2007 so you might want to supplement this with some more modern papers.
- [A long hard look at MCG-6-30-15 with XMM-Newton](https://ui.adsabs.harvard.edu/abs/2002MNRAS.335L...1F/abstract)

## Data

- [XMM-Newton Science Archive](https://www.cosmos.esa.int/web/xmm-newton/xsa) provides access to the European XMM-Newton data archive
- [HEASARC](https://heasarc.gsfc.nasa.gov/) is the NASA high-energy astrophysics data archive which includes XMM-Newton data. This page includes a link to the various ways to search the [archive](https://heasarc.gsfc.nasa.gov/docs/archive.html). I quite like the [legacy interface](https://heasarc.gsfc.nasa.gov/cgi-bin/W3Browse/w3browse.pl) but you might prefer somethig more modern!
- [Tartarus databse](https://heasarc.gsfc.nasa.gov/FTP/asca/data/tartarus/) of ASCA observations of AGN. We won't be using ASCA data but it is still very interesting to look at this database and papers that have used it

## Software

- [XMM SAS](https://www.cosmos.esa.int/web/xmm-newton/sas) is the main software used to pipeline process and extract XMM-Newton data
- [An introduction to XMM-Newton data analysis](http://heasarc.gsfc.nasa.gov/docs/xmm/abc/) from NASA HEASARC
- [The Absolute Beginner's Guide to XMM](https://heasarc.gsfc.nasa.gov/FTP/xmm/docs/The_Absolute_Beginners_guide_to_XMM_v1.pdf) from NASA HEASARC
- [ABC Guide](https://heasarc.gsfc.nasa.gov/docs/xmm/abc/abc.html) introduction to XMM-Newton data analysis from NASA HEASARC. There is also a [streamlined ABC guide](https://heasarc.gsfc.nasa.gov/docs/xmm/sl/intro.html)
